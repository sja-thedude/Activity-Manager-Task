## Activity Manager Task

A React application to add, edit, and manage activities using dynamic forms. The app allows users to input details for each activity and view them in a card-based layout.

🚀 Features
	•	Create a new activity with details (via local storage)
	•	View list of added activities
 	•	View individual activity details
	•	Responsive design with dynamic routing
 	•	Fetched data is stored via API

📦 Tech Stack
	•	React (with React Router)
	•	Local Storage (to preserve activity data across sessions)
	•	JavaScript (ES6+)
	•	CSS

🛠️ Getting Started
	1.	Clone the repository

git clone https://github.com/your-username/activity-manager-task.git
cd activity-manager-task


	2.	Install dependencies 

`npm install`


	3.	Run the app

`npm start`


	4.	Open your browser at http://localhost:3000

🧪 Scripts
	•	npm start – Run the app in development mode
	•	npm test – Run tests (if added)
	•	npm run build – Build the app for production
	•	npm run eject – Eject from Create React App configuration

💡 Notes
	•	All activities are saved in local storage, so reloading the page retains the added data.
	•	To preserve the form data when navigating back, ensure local state updates are reflected in global state or localStorage.
